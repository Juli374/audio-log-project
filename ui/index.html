Корректировка через Claude
Только короткая диктовка. Лёгкая — пунктуация и явные ошибки, слова не трогает. Полная — заменяет неподходящие слова и чинит грамматику для итогового корректного текста. Длинные сессии не задеваются.
Перевод через Claude
Постобработка транскрипта: перевод на выбранный язык через Anthropic API. Если совпадает с языком распознавания — перевод пропускается.
