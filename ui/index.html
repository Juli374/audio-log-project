Anthropic API ключ
Нужен для перевода и/или корректировки пунктуации через Claude. Получить: console.anthropic.com
Корректировка через Claude
Лёгкая — пунктуация и явные ошибки, слова не трогает. Полная — заменяет неподходящие слова и чинит грамматику для итогового корректного текста.
Перевод через Claude
Постобработка транскрипта: перевод на выбранный язык через Anthropic API. Если совпадает с языком распознавания — перевод пропускается.
